1. THE PITCH: WHY SYNAPSE OS EXISTS
--------------------------------------------------------------------------------
Almost every "educational AI tool" built today wraps a React frontend around a
cloud API key and bundles it inside Electron—eating 800 MB of RAM just to render
a button and dying the moment school Wi-Fi drops.

SynapseOS takes the exact opposite approach:
  - Native compiled Linux GTK3 + Cairo 60 FPS AI Workbench ("Synapse Studio")
    that uses ~24 MB of RAM and cold-starts in 0.1 seconds.
  - Built on a stripped-down Debian 12 Bookworm (minbase) + Xorg + Openbox + Tint2
    desktop environment with custom sysctl and LZ4 ZRAM tuning.
  - Ships 100% offline out-of-the-box with a two-tier local AI assistant:
      Tier A: A 92 KB SQLite FTS5 BM25 Knowledge Base (<1 ms deterministic lookup)
      Tier B: A pre-baked, custom-conditioned 3.8B LLM (cortex-phi3:latest, Q4_K_M,
              2.2 GB) running locally via Ollama with SIMD & mlock optimizations.
  - Bridges the gap between "playing with GUI sliders" and "writing real Python"
    via bidirectional Slider-to-Code synchronization and an 8-second timeout-
    guarded Python coding sandbox with kid-friendly error explanations.

2. LAYER-BY-LAYER SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
A. BASE OPERATING SYSTEM (Debian 12 Bookworm Minbase + Potato Kernel Tuning)
   - Window Manager: Openbox 3 + Tint2 status panel (zero compositor bloat)
   - Display Layout: Auto-maximizing 1280x800 classroom-safe dark theme (#0e1017)
                     using pure Basic Multilingual Plane (BMP) vector glyphs so it
                     needs zero 30 MB color-emoji font packages.
   - Memory & Swap Tuning (/etc/sysctl.d/99-synapse-potato.conf & /etc/default/zramswap):
       * LZ4 ZRAM Swap:      50% of physical RAM (ultra-fast L1/L2 cache compression
                             for OS/glibc/Python heap pages)
       * vm.swappiness = 25: Protects high-entropy 4-bit quantized LLM weights from
                             being evicted into ZRAM swap during token generation
       * vm.vfs_cache_pressure = 50: Keeps directory/inode caches hot in RAM
       * vm.dirty_ratio = 15 / vm.dirty_background_ratio = 5

B. TWO-TIER LOCAL AI COPILOT (CortexEngine: cortex/engine.py)
   - Fast Path (<1 ms, 0.68 ms avg):
       * SQLite FTS5 BM25 index (cortex/data/cortex_kb.sqlite, 92 KB).
       * Answers Linux sysadmin queries (?? <question>) and AI hyperparameter
         questions (?ai <topic>) deterministically in sub-millisecond time.
       * Allows Tier 1 netbooks (1 GB RAM, no LLM loaded) to still have an instant,
         offline Linux & AI assistant.
   - Deep Path (Local Offline LLM — cortex-phi3:latest, 3.8B Q4_K_M, 2.2 GB):
       * Pre-baked directly into the Live ISO at /usr/share/ollama/.ollama/models
         and served by systemd (ollama.service on 127.0.0.1:11434).
       * Hardware-Aware SIMD & Memory Pinning (cortex/engine.py):
           1. Inspects /proc/cpuinfo on startup for avx2, avx, and sse4_1 flags.
           2. Dynamically scales context window (num_ctx) and max tokens:
                - Non-AVX2 / <3.8 GB RAM: num_ctx = 1024, num_predict = 300
                  (and prioritizes sub-1B fallback models like cortex-nano /
                   qwen2.5:0.5b if installed so Core 2 Duo / SSE4.1 CPUs don't stall).
                - Tier 2 (4 GB–7.5 GB RAM + AVX2): num_ctx = 2048, num_predict = 500
                - Tier 3 (8 GB+ RAM + AVX2):       num_ctx = 4096, num_predict = 900
           3. Sets use_mlock = True whenever physical RAM >= 3.8 GB so the 2.2 GB
              Q4_K_M model weights stay locked in physical RAM and never thrash ZRAM.
           4. Uses a 60-second HTTP timeout to tolerate first-run cold reads off
              slow USB 2.0 flash drives or optical media before the Linux page cache
              warms up.
   - Custom QLoRA Fine-Tuning Pipeline (cortex/forge/):
       * Includes cortex_phi3_train.jsonl (56 KB curated multi-turn dataset),
         Modelfile.phi3, and train_phi3_qlora.py (4-bit NF4 QLoRA trainer targeting
         Phi3ForCausalLM qkv_proj, o_proj, gate_up_proj, down_proj).
       * Built-in GPU hardware guardrail: blocks accidental CPU QLoRA backprop over
         3.8B parameters on classroom potatoes unless --force-cpu is explicitly passed.

C. SYNAPSE STUDIO: 6 NATIVE 60 FPS POINT-AND-CLICK AI LABS (workbench/labs.py)
   All 6 engines are written in pure Python + NumPy (zero PyTorch/CUDA runtime
   overhead required to run the simulations at 60 FPS):
   1. [NEAT Rocket Moon Lander] (Neuroevolution)
      - 8 continuous sensors -> evolving arbitrary-topology neural graph -> 4 thrusters.
      - Sliders: Gravity (Moon 1.62 / Mars 3.72 / Earth 9.8), Crosswind, Fuel,
        Population Size, Add-Neuron Rate, Add-Synapse Rate, Weight Mutation Power.
   2. [NEAT Self-Driving Lidar Car] (Autonomous Raycast Control)
      - 5-beam 2D Lidar raycasting around a closed race track + live neural graph.
      - Sliders: Lidar Sensor Range, Max Speed, Steering Agility, Track Lane Width,
        Population Size, Structural Mutation Rates.
   3. [RL Hazard GridWorld] (Tabular Reinforcement Learning: Q-Learning vs. SARSA)
      - Classic Sutton & Barto lava cliff-walking showdown with live Bellman V(s)
        heatmap and optimal policy arrows (N/S/E/W) in every grid cell.
      - Sliders: Learning Rate (alpha), Discount Factor (gamma), Exploration (epsilon),
        Treasure Reward, Lava Penalty, Wind Slip Probability, Algorithm Toggle
        (Off-Policy Q-Learning vs. On-Policy Safe SARSA).
   4. [CartPole Inverted Pendulum] (Classic Control / Neuro-Policy Evolution)
      - Motorized cart on a track balancing an unstable pole under wind gusts.
      - Sliders: Gravity, Pole Length, Motor Force, Wind Gusts, Population, Mutation.
   5. [Neural Network Backprop] (2D Multi-Layer Perceptron Decision Boundaries)
      - Real-time tanh MLP forward/backward propagation with live 2D probability
        contour rendering across 4 datasets: XOR Gate, Concentric Rings, Two Moons,
        and Intertwined Spiral.
      - Sliders: Dataset Selector, Hidden Layer Neurons, Learning Rate (eta),
        L2 Regularization (lambda), Data Noise.
   6. [Predator-Prey Swarm] (Multi-Agent Co-Evolutionary Boids)
      - Emergent flocking, foraging, and predator evasion with evolving sensory radii.
      - Sliders: Prey Flock Size, Predator Count, Vision Radius, Max Speeds, Food
        Spawn Density, Genetic Mutation Rate.

       * Combines a bounded local Softmax Sliding Window [t - W + 1, t] with a

         with zero AVX2 or external library dependencies (`libc` + `-lm` only).
       * Used in `CortexSlidingWindowCompressor` to score and compress evicted RAG/
         history chunks so CPU prompt evaluation stays bounded (~100 tokens).
